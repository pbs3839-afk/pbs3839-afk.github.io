# Portfolio design references

The portfolio uses the user's own project screenshots. External examples were consulted for typography, spacing and presentation; their images are not used in the website.

- Robert Mayer portfolio on Pinterest: https://kr.pinterest.com/pin/862720872389248921/
  - Reference for a large name-led introduction, restrained dark background and compact navigation.
- UPROCK — NEW WEBSITE on Pinterest: https://kr.pinterest.com/pin/20688479530363011/
  - Reference for project-specific background colors, clearly framed previews and spacing between projects.

The implementation presents a wide TodoList panel, a staggered pair of fruit shop and bank previews, and a wide movie panel. On mobile, projects follow a single column. Scroll reveals respect reduced-motion preferences. Browser frames are made with HTML and CSS. The actual TodoList, fruit shop, bank and movie project files were not modified.
